# 🚀 Codify

A lightweight online code compiler that allows users to write, compile, and execute code in multiple programming languages directly from the browser.

## 🌐 Live Demo

🔗 **Frontend:** https://codify-azure.vercel.app/

⚙️ **Backend API:** https://codify-rt7b.onrender.com

---

## ✨ Features

- 🌍 Multi-language support (C, C++, Java, Python, JavaScript)
- 📝 Custom code editor
- 🔢 Line numbering
- ⌨️ Auto-closing brackets
- 📐 Smart auto-indentation
- ⚡ Real-time code execution
- ☁️ Cloud-based compilation

## 🚀 Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/Codify.git

cd backend
npm install
npm start
```

Open `frontend/index.html` using Live Server.
